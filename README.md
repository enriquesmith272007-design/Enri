### 2. 📝 Ejercicio de Penalización Pendiente (Defensa Presencial)

Tenés un ejercicio de nivelación/penalización asignado que debés presentar y defender presencialmente en el laboratorio.

- **Tema:** Arrays, Objetos Literales y Método `.push()`
- **Ubicación en este repo:** [`ejercicio-extra/README.md`](./ejercicio-extra/README.md)

#### Consigna:
1. Crear un array vacío llamado `carrito`.
2. Escribir una función `agregarProducto(nombre, precio)` que cree e inserte un objeto `{ nombre, precio }` dentro del array `carrito` utilizando `.push()`.
3. La función debe retornar la cantidad total de productos almacenados en el carrito utilizando la propiedad `.length`.

#### Defensa Oral Presencial (2 minutos en laboratorio):
Durante la revisión en clase se evaluará la comprensión del código con 2 preguntas:
1. ¿Cómo funciona el método `.push()` y en qué posición del array ubica el nuevo objeto?
2. ¿Cómo accedés específicamente a la propiedad `precio` del primer producto guardado en `carrito`?
